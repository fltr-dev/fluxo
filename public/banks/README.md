# Logos dos bancos

Os SVGs desta pasta vêm do repositório [Tgentil/Bancos-em-SVG](https://github.com/Tgentil/Bancos-em-SVG) (branch `main`), na variante só com o símbolo. Foram limpos (sem metadados do Inkscape, sem `width`/`height`, coordenadas arredondadas) e, quando o símbolo sumiria sobre a cor do banco, recoloridos em branco.

O repositório não tem licença. As marcas e os logotipos pertencem aos seus donos e aparecem aqui só para identificar a conta de cada banco.
